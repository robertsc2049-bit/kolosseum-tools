# kolosseum.tools

Public tools surface for Kolosseum.

## Position

This repo is not the core Kolosseum platform. It is the public utility surface.

The design direction is:
- dark graphite shell
- lime-green controlled accents
- equal tool cards
- one active tool at a time
- public calculators and logs only
- no platform claims

## Run

npm install
npm run check
npm run start

## Current tools

- Event Block Calculator
- IronClock
- Gym Share
- Session Log
- Meet Planner
- Load Sheet

## Rule

This site should look like Kolosseum, but do less than Kolosseum.
