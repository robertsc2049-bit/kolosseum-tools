Clean static rebuild of the Kolosseum Tools public utility surface.

## Principles

- Wireframe first.
- Shared components before page-specific overrides.
- External JavaScript only.
- No decorative layout competing with active tool panels.
- Desktop, half-screen, tablet, iPhone, and Android behaviour defined before page implementation.
