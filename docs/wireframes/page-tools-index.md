# Page Wireframe: Tools Index

## Route

`/tools/`

## Purpose

Show all public Kolosseum tools as direct-use utility pages.

## Commercial headline

Structured tools. Direct outputs.

## Primary action

Open a selected tool.

## Secondary action

Return home.

## Page zones

1. Header.
2. Text-only hero.
3. Tool directory grid.
4. Optional short operating principles strip.

## Must have

- Six tool cards.
- Icons.
- Short descriptions.
- Direct links to dedicated tool pages.

## Must not have

- Dashboard preview.
- Public service/status card.
- Side navigation panel.
- Redundant “Current Kolosseum.tools pages” wording.
- Large “Open” pills that collide with titles.

## Tool card layout

Desktop:

- Three columns when width allows.
- Two columns at constrained desktop widths.
- One column on mobile.

Card internal layout:

- Icon left.
- Title and description middle.
- Small `+` action mark right on desktop.
- Hide action mark on narrow mobile if space is tight.

## Responsive

Desktop: align with home page spacing.

Half-screen: do not clip heading or cards.

Mobile: H1 must wrap cleanly and remain inside viewport.
