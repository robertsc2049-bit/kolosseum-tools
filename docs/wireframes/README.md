# Kolosseum Tools Wireframes

This folder is the implementation source of truth for Kolosseum Tools page structure.

Before creating or changing HTML, CSS, or JavaScript, update or confirm the relevant wireframe file. The wireframes define page purpose, page zones, component usage, responsive behaviour, and exclusions.

Implementation rule: do not add decorative cards, status panels, duplicate navigation, or dashboard previews unless the page wireframe explicitly allows them.
