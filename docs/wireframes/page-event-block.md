# Page Wireframe: Event Block Calculator

## Route

`/tools/event-block-calculator/`

## Purpose

Calculate block start, taper start, and event day from a single event date.

## Primary action

Calculate.

## Secondary action

Copy result.

## Page zones

1. Header.
2. Tool hero.
3. Full-width active tool panel.
4. Related tools rail.

## Active tool panel

Left/form column:

- Event date.
- Block length.
- Taper length.
- Calculate button.

Right/result column:

- Waiting/ready state.
- Block start.
- Taper start.
- Event date.
- Copy result.

## Must not have

- Decorative status card.
- Side Other Tools card.
- Dashboard preview.

## Responsive

Desktop: form left, result right, full working page width.

Tablet/mobile: stack form then result. Result date cards stack if needed.
