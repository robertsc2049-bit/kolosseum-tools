# Page Wireframe: Session Log

## Route

`/tools/session-log/`

## Purpose

Record local factual session entries in the browser and copy the latest entry.

## Primary action

Save session entry.

## Secondary action

Copy latest entry.

## Page zones

1. Header.
2. Tool hero.
3. Active tool panel.
4. Related tools rail.

## Active tool panel

Form column:

- Session date/time.
- Session title or location.
- Notes/items.
- Save button.

Result column:

- Latest entry.
- Local entry list.
- Copy latest.

## Data rules

Local-only. No account. No remote storage unless future page spec changes.

## Must not have

- Decorative status card.
- Large workflow explainer.
- Duplicate related tools card.

## Responsive

Desktop: input left, log right.

Mobile: input first, latest entry second, list third.
