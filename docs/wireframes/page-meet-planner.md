# Page Wireframe: Meet Planner

## Route

`/tools/meet-planner/`

## Purpose

Calculate meet setup, travel day, and meet day from a meet date.

## Primary action

Calculate meet dates.

## Secondary action

Copy result.

## Page zones

1. Header.
2. Tool hero.
3. Active tool panel.
4. Related tools rail.

## Active tool panel

Form column:

- Meet date.
- Setup offset.
- Travel offset.
- Optional notes.
- Calculate button.

Result column:

- Setup date.
- Travel date.
- Meet date.
- Copy result.

## Must not have

- Decorative status card.
- Side Other Tools card.

## Responsive

Desktop: form left, result right.

Tablet/mobile: stack form then result.
